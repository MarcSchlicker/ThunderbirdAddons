ECHTE CALDAV-KALENDER

Nextcloud-Kalender in Thunderbird

Verwendet die Nextcloud-Anmeldung oben. Termine bleiben echte CalDAV-Termine und werden von Thunderbird synchronisiert. Der JSON-Modulabgleich ist davon getrennt. Die App erhält diese Kalender über den Hub.

Bitte zuerst Nextcloud anmelden, dann Kalender abrufen.

Ein Klick legt einen echten Kalender in deinem Nextcloud-Konto an. Bereits vorhandene Kalender werden nicht gelöscht oder ersetzt. Für direkten CalDAV-Abgleich auf Android bleibt ein Android-Kalenderanbieter nötig; TB-Connect greift derzeit über den Desktop-Hub darauf zu.

MODULQUELLE

Modul aus GitHub oder einer anderen Quelle hinzufügen

Gib die HTTPS-Adresse einer tb-connect-module.json oder direkt ein GitHub-Repository ein. Der Hub prüft die Beschreibung, lädt XPIs nur nach deinem Klick herunter und überträgt ausgewählte Mobil-Pakete erst beim nächsten Abgleich.

EIGENE MODULE

Alles, was ein eigenes Modul braucht

Ein Repository enthält eine tb-connect-module.json mit quadratischem Logo, optionaler Desktop-XPI und optionalem Mobil-Paket. Der Hub überträgt ausschließlich JSON-Zustände pro Modul-ID. Mobil-Pakete sind beschreibende Datenpakete; TB-Connect Mobil führt keinen Code aus einem Repository aus.

So läuft die Datenübertragung
  1. Du wählst im Hub ein Modul für Mobil aus.
  2. Beim nächsten token-geschützten Abgleich erhält das Handy den Katalog und zeigt „Download verfügbar“. Erst der Klick in der App installiert das geprüfte JSON-Paket in den privaten Speicher.
  3. Jedes Modul synchronisiert nur seinen eigenen JSON-Namensraum. Desktop-XPIs werden mit Speichern-Dialog geladen und anschließend in Thunderbird sichtbar manuell bestätigt.

Die vollständige, versionierte Schnittstelle steht im Repository in docs/MODULE_BRIDGE_PROTOCOL.md.
